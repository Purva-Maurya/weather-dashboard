# 🌤️ Weather Dashboard

A modern Full-Stack Weather Dashboard built with React, Vite, Express.js, MongoDB Atlas, and OpenWeather API.

## 📸 Features

- 🌤️ Real-time Weather
- 📅 5-Day Weather Forecast
- 🔍 Search Any City
- 💾 Search History (MongoDB)
- 📍 City & Country Information
- 🌡️ Temperature & Feels Like
- 💧 Humidity
- 🌬️ Wind Speed
- ⚡ Animated UI with Framer Motion
- 📱 Responsive Design

### Frontend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Purva-Maurya/weather-dashboard.git
```

### Backend

```bash
cd weather-dashboard-api
npm install
npm start
```

### Frontend

```bash
cd weather-dashboard-frontend
npm install
npm run dev
```

## 🌍 API

Current Weather

```
GET /api/weather?city=Delhi
```

Forecast

```
GET /api/forecast?city=Delhi
```
